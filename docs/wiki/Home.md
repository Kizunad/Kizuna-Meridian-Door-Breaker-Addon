# 破门斩数据目录

破门斩是独立的一书三卷八式数据包。正式包提供功法 `.txtpb` 清单、式名语言资源、六种伤害类型、物品标签和可劈门标签。
执行行为由功法库和宿主提供，本仓不包含 Java 运行时代码。
功法库从清单生成上、中、下卷物品并列入「功法」创造栏，右键成功后学会整卷。
八式均提供 `presentation.display_name` 与完整使用说明，zh_cn/en_us 覆盖书、卷、式和卷轴物品名称。
学习后阅读页从目录显示费用、冷却、施放时长和动作条件；多式长卷可滚动，正文不再显示原始 ID。

| 卷 | 内容 | 功法 |
|---|---|---|
| 上卷 `upper` | 木门 | 叩门、破门、撞门 |
| 中卷 `middle` | 铁门 | 破盾、横扫、掩门 |
| 下卷 `lower` | 万门 | 连门、万门一斩 |

所有数值都是设计占位值。冷却从收势结束开始，承接依前式和起播时刻声明；同次施放按 `dedup_group` 去重。
八式的 `movement_speed_multiplier` 均为 0.4，从起手至收势允许以原速的 40% 主动移动；
不再使用 `lock_movement`。冲刺冲量保持目录原速，承接和中断通过同一清理身份移除限速。
万门一斩的组织修正曲线在起手提交，并在打断后继续完整运行。首版没有受保护物品标签。

叩门、破门、撞门已接入 PA 专属主副手动画。叩门在 900、1250、1700 毫秒连敲三下，
倍率依次为 0.3、0.3、0.9，合计 1.5；破门、撞门分别在 3200、2400 毫秒命中。
叩门起手 900、发力 800、收势 1300 毫秒，总长 3 秒，起手仍不能被伤害打断。
每击独立去重、重新检查范围，整次最多打同一个目标，末击才扣一次耐久。
撞门三次冲量在 1550、1800、2050 毫秒，
位于动画 1550–2250 毫秒的迈步窗口，后两次与落脚事件对齐。
玩家和卫道士共用人体内容映射，左右惯用手在 PA 运行时镜像。
PA 的 `hit` 事件是客户端通知；当前没有叩门命中表现订阅者，伤害、闪红与调试日志来自服务端真实伤害链。
因此保留动画原有末击通知和全部关键帧，前两击对齐 0.90、1.25 秒的腕部接触帧。
其余五式尚无专属片段，仍借用对应主副手挥砍。
